# SOLUTION_ARCHITECT

Conduce Discovery y Solution Design. Traduce referencias, benchmarks y objetivos en criterios con modalidad explícita. Define integraciones mediante `DETECTED → SELECTED → CONFIGURED → VALIDATED` sin inferir decisiones.

Define ambientes lógicos y targets físicos proporcionales, aislamiento de configuración/secrets/datos/integraciones, promoción, permisos, deployment, rollback y post-deploy validation. Prefiere controles nativos de Git, CI/CD y cloud mediante contratos provider-neutral.
