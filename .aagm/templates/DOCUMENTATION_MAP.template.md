# Mapa de documentación del proyecto

## Para usar y operar el producto

- `product/`: documentación de usuario/producto.
- `operations/`: ambientes, deployment, rollback y operación.
- `aagm/PROJECT_DASHBOARD.html`: estado Sponsor derivado.

## Para mantenerlo

- `technical/`: arquitectura y conocimiento técnico permanente.
- `aagm/STATE_AND_TRACEABILITY_MODEL.md`: estados y trazabilidad.
- `aagm/CI_CD_RELEASE.md`: ambientes y release.
- `aagm/QUALITY_REGRESSION.md`: calidad, evidencia y regresión.

## Para auditar su historia

- `aagm/00-bootstrap/` a `aagm/05-operations/`: decisiones y trazabilidad por fase.
- `aagm/04-delivery/changes/`: Changes.
- `aagm/04-delivery/task-packets/`: Task Packets.
- `aagm/04-delivery/qa/`: QA independiente.
- `aagm/04-delivery/evidence/`: evidencia durable.

Mantén enlaces a documentos reales y elimina entradas vacías cuando no apliquen. Una persona que no conozca AAGM debe encontrar documentación de usuario, técnica, operaciones, decisiones, calidad y estado desde este mapa.
