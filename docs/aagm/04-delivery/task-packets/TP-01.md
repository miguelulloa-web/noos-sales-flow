## Alcance autorizado

- **Objetivo y modalidad:** Implementar la infraestructura base del servidor Express, motor SQLite persistente local (`data/noos_sales_flow.db`), autenticación robusta con hash de contraseñas y sesiones con tokens hasheados, middleware de roles y servicio de auditoría append-only (`MUST`).
- **Incluye:**
  - Inicialización del proyecto Node.js (`package.json`, Express, SQLite nativo `node:sqlite`).
  - Migración inicial de tablas: `users`, `auth_sessions`, `audit_log`, `ai_config`.
  - Hashing seguro de contraseñas con `bcrypt` (cost factor 10+) en `users.password_hash`. **Ninguna contraseña inicial se escribe en código ni en Git.**
  - Inicialización de usuarios de prueba (`admin` y `operador_demo`) mediante variables de entorno locales (ej. `INITIAL_ADMIN_PASSWORD`) o comando seguro de inicialización (`npm run init-db`).
  - Almacenamiento de tokens de sesión: el token emitido al cliente es una cadena criptográfica aleatoria de alta entropía (32 bytes hex), pero **en la tabla `auth_sessions` se almacena exclusivamente su hash SHA-256 (`session_token_hash`)**, evitando exposición en caso de volcado de base de datos.
  - Cookies de sesión: `HttpOnly=true`, `SameSite=Lax`, `Path=/`, `Max-Age=86400` (24h), y flag `Secure` condicionado a HTTPS (`secure: process.env.NODE_ENV === 'production' || req.secure`), documentando su funcionamiento en HTTP local (`localhost`).
  - Protección en servidor contra solicitudes externas no autorizadas: middleware que valida encabezados `Origin` y `Referer` (restringiendo a `localhost:3000`) o validación de header custom en peticiones que modifiquen estado (POST/PUT/DELETE).
  - Middleware de autorización en servidor diferenciando roles `ADMIN` y `OPERATOR`.
  - Endpoints de autenticación: `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me`.
  - Servicio de `audit_log` estrictamente append-only (sin métodos de actualización ni borrado en la capa de datos).
- **Excluye:** Integración con Gemini API (TP-02), interfaz de triage (TP-03), gestión de acciones (TP-04), preparación de demo (TP-05).
