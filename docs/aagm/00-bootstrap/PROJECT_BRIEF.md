# Project Brief — Noos Sales Flow

- **Problema/oportunidad:** Pérdida y desorganización de solicitudes comerciales y de cotización recibidas en texto libre en empresas B2B. Necesidad de validar una solución comercial de NoosAdvisory mediante un MVP funcional para demostraciones ante potenciales clientes.
- **Usuarios:** 
  - *Primario:* Responsable de ventas, atención comercial u operaciones de PyME B2B.
  - *Administrador/Demostrador:* Miguel Ulloa (con datos sintéticos para demos).
- **Resultado y criterios de éxito:** Aplicación web utilizable de extremo a extremo que procesa solicitudes comerciales con IA real, extrae datos estructurados verificables, permite edición humana, asignación, seguimiento, generación de borrador de respuesta, persistencia garantizada ante reinicios y exportación.
- **Alcance / fuera de alcance:**
  - *Dentro de alcance:* Formulario de ingreso de texto libre, procesamiento IA real, trazabilidad de evidencia textual, corrección manual, asignación de responsable/acción/fecha, borrador de respuesta con revisión humana, bandeja de pendientes/vencidas, historial de cambios, exportación de datos, persistencia en base de datos.
  - *Fuera de alcance:* Integración con clientes de correo saliente directo, bots de WhatsApp, conectores a CRM/ERP de terceros, calendario o ejecución autónoma sin revisión humana.
- **Restricciones/riesgos:** Utilizar exclusivamente datos sintéticos durante pruebas y demos; control estricto de costos de API de IA; persistencia obligatoria comprobable; despliegue previsto en GCP.
- **Idioma Sponsor:** `es`
- **Nivel / autonomía / perfil:** Nivel A · CONTROLLED · LIMITED
- **Changes iniciales:** Se derivarán durante Discovery a partir del documento de alcance `ALCANCE_MVP_FUNCIONAL_ANTIGRAVITY_AAGM_V0.2.md`.
- **Ambientes previstos:** DEV (local/validación empírica) y CLOUD/STAGE (GCP).
