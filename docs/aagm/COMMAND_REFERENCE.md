# Referencia de comandos v1.10

| Comando | Resultado | Límite |
|---|---|---|
| `/aagm-bootstrap` | Inicializa y registra transición a Discovery | No crea producto/CI/cloud |
| `/aagm-status` | Sincroniza, resume y abre Dashboard | Vista derivada |
| `/aagm-continue` | Ejecuta una unidad autorizada | Stop obligatorio |
| `/aagm-approve` | Registra aprobación tipada y scope-bound | IDE Accept no cuenta |
| `/aagm-request-changes` | Registra Change e impacto | No implementa |
| `/aagm-run-qa` | QA independiente con evidencia | Publica y se detiene |
| `/aagm-release-gate` | ORCHESTRATOR_PM evalúa release | Separado de QA |
| `/aagm-sync-dashboard` | Actualiza datos determinísticamente | No rediseña |
| `/aagm-push` | Revisa y sincroniza remoto | ASK en CONTROLLED |
| `/aagm-audit` | Audita instalación/gobierno/evidencia | No repara decisiones |
| `/aagm-pause` | Detiene y registra handoff seguro | No declara DONE |
| `/aagm-feedback` | Registra feedback metodológico | No asigna MF automático |
| `/aagm-help` | Ayuda localizada | Modelo semántico único |
